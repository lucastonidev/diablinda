# Assets da Diablinda

Coloque o banner promocional oficial do projeto neste diretório com o nome:
`banner.png` (resolução recomendada: 1280x640px ou proporção 2:1).

Os arquivos de documentação (`README.md`, `README.en.md` e `README.es.md`) já estão configurados para exibir automaticamente a imagem a partir de `assets/banner.png`.
